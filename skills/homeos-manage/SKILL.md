# homeos-manage

Run `homeos guide` first and follow its output as the operating guide for
this task. It is generated by the installed binary, so it always matches the
homeos version on this machine.

If its stderr carries a `homeos: vX.Y.Z available` line, tell the user once
and ask whether to update homeos before continuing. If they say yes, update it
the way the guide's self-managing section describes, then run
`homeos guide` again: the guide changes with the binary. If they decline,
continue and do not raise it again in this session.
